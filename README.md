# Duel Legends Arena

Jogue: https://alissoneves.github.io/Duel-Legends-Arena/

Versão atual: **2.5.3** (servidor 2.1). Veja o [histórico](CHANGELOG.md).

## Como editar o jogo

1. Altere os arquivos em `src/js/` (cada um é um assunto: online, loja, partida, telas...).
2. Rode `node build.js` para gerar o `index.html`.
3. Teste abrindo o `index.html` no navegador.

O `index.html` da raiz é gerado: não edite ele direto.
